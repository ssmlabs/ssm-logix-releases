# SSM Logix

An offline records app for Windows. Beta: keep your paper registers alongside.

## Download

[Download SSMLogix.exe](https://github.com/ssmlabs/ssm-logix-releases/releases/download/v1.0-beta/SSMLogix.exe)

## Install

1. Download the file and double-click it. There is no installer.
2. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**.
3. Windows 11 with Smart App Control on blocks new apps that are not code-signed. Use the same steps above. A Microsoft Store version is planned.

## How to use

1. First launch: one screen. Choose a folder, type your name, set a 6-digit Supervisor PIN, and keep the recovery key it shows (print it or save it to a pen drive).
2. Daily use: open the app, pick your name, type your PIN on the keyboard or the keypad, and enter your day's records in the registers or on the Counter.
3. At the end of the day, close the day and print or save the daily summary as a PDF.
4. Use the backup button to copy your books to a pen drive. To get a newer version, click **Check for updates**.

Everything stays on your computer. No internet is needed.

## Problems?

In the app, click Report a problem, then email the saved file to ssmlogix.help@gmail.com.
